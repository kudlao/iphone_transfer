# Hush Photo — инструкция (Windows 10/11 x64)

[Русский](README.md) | [English](README_EN.md) | [简体中文](README_ZH.md)

**Hush Photo** — бесплатная Windows-программа с открытым исходным кодом для экспорта фото и видео с iPhone на компьютер по USB. Удобная альтернатива ручному копированию из DCIM: выбор медиафайлов, сохранение оригиналов HEIC/JPG/MOV/MP4, поддержка Live Photos и повторный экспорт без повторного копирования проверенных файлов.

### Возможности

- **Экспорт фото и видео:** HEIC, HEIF, JPEG, PNG и другие поддерживаемые изображения, MOV/MP4 без перекодирования.
- **Live Photos:** сохранение оригинальной фотографии и парного видео MOV.
- **Безопасный перенос:** только чтение данных iPhone, работа через USB/AFC, исходные файлы не изменяются.
- **Повторный экспорт:** локальный манифест, SHA-256 для уже полученных копий и пропуск ранее проверенных файлов.
- **Удобная организация:** папки по годам и месяцам, единая папка или исходная структура DCIM.
- **Просмотр и контроль:** миниатюры, выбор фото/видео, прогресс, скорость и приблизительное оставшееся время.
- **Portable:** сборка для Windows 10/11 x64; Python не нужен для запуска готовой сборки.

> **Важно:** это экспорт фотографий и видео, а не полная резервная копия iPhone. Для USB-доступа нужен набор `libimobiledevice`. Возможны особенности AFC, iCloud Photos и альбома «Недавно удалённые».

**Лицензия:** [MIT](LICENSE) — бесплатное использование, изменение и распространение, включая коммерческое, при сохранении уведомления об авторских правах и текста лицензии. Сторонние компоненты распространяются на собственных условиях лицензирования.

## 1. Подготовка

- Подключите iPhone по USB, разблокируйте и подтвердите «Доверять этому компьютеру». На Windows должны быть установлены Apple Devices / Apple Mobile Device Support.
- Для USB-импорта нужен распакованный набор `libimobiledevice` для Windows x64: `afcclient.exe` и DLL из того же архива. Важно указывать **папку**, а не путь к самому `afcclient.exe`.

### Где указать путь к AFC

Выберите **один** из способов:

**Способ 1 — рядом с программой (удобнее для portable).** Создайте папку `native` рядом с `HushPhoto.exe` и скопируйте в неё `afcclient.exe` и DLL из набора `libimobiledevice`. Например: `HushPhoto\native\afcclient.exe`. Для запуска из исходников папка `native` должна находиться рядом с `iphone_usb.py`.

**Способ 2 — переменная окружения (без копирования файлов).** В PowerShell перед запуском приложения задайте путь к каталогу утилит:

```powershell
$env:HUSH_AFC_TOOLS = 'D:\Tools\libimobiledevice'
```

Замените пример собственным путём к папке, в которой лежит `afcclient.exe`. Переменная действует только в этом окне PowerShell и наследуется запущенными из него процессами. Для постоянной настройки используйте системные параметры Windows → «Переменные среды», создайте пользовательскую `HUSH_AFC_TOOLS` и перезапустите приложение.

**Способ 3 — системный `PATH`.** Добавьте папку с `afcclient.exe` в `PATH` Windows и перезапустите приложение. Не нужно добавлять полный путь до EXE.

**При сборке portable EXE:** запустите `build_portable.bat` из командной строки, в которой определена `HUSH_AFC_TOOLS`. Сборочный скрипт скопирует исполняемые файлы и DLL в `dist\HushPhoto\native`; после этого путь на другом компьютере задавать не придётся. Если переменная не задана, утилиты в portable-архив автоматически не включаются.

**Проверка:** в PowerShell из каталога утилит выполните `.\idevice_id.exe -l` и `.\afcclient.exe ls /DCIM`. Для проверки настроенного пути можно выполнить `Test-Path (Join-Path $env:HUSH_AFC_TOOLS 'afcclient.exe')` — должно быть `True`.

## 2. Запуск

**Готовый portable EXE:** распакуйте *всю папку* `HushPhoto` из portable-архива и запустите `HushPhoto.exe`. Python для запуска не нужен. Не переносите один EXE без остальных файлов.

**Запуск из исходников:** установите Python 3.11+ (x64), распакуйте проект, запустите `start_windows.bat`. Для первого запуска нужен интернет для установки зависимостей.

**Сборка portable:** при установленном Python 3.11+ (x64) запустите `build_portable.bat`. Скрипт установит зависимости, запустит тесты и при успехе создаст `dist\HushPhoto-Windows-Portable.zip`; приложение — `dist\HushPhoto\HushPhoto.exe`. Если `afcclient.exe` отсутствует в указанном каталоге, USB-импорт не будет работать без дополнительной настройки.

## 3. Экспорт фотографий и видео

1. Выберите источник: **iPhone по USB** или **локальная папка**.
2. Для iPhone нажмите **Найти фото и видео** на стартовом экране и дождитесь появления списка. Затем используйте **Обновить** для повторного сканирования. В верхней части медиатеки переключайтесь между **Фото** и **Видео**. В группе **Видео** доступны дополнительные фильтры **Все видео**, **Видеоролики** и **Live Photos**. Видеоролики — MOV/MP4 без найденной парной фотографии; Live Photos — MOV с фотографией того же имени в той же папке. Это классификация по имени и каталогу, а не по внутреннему идентификатору Apple, поэтому возможны неточности. Выбор относится только к текущей группе: чтобы отдельно скопировать видео, откройте «Видео» и выберите нужные MOV/MP4. Миниатюры фотографий подгружаются автоматически при прокрутке и переключении страниц — никаких отдельных кнопок загрузки не требуется.
3. Укажите папку назначения и нажмите **Экспортировать выбранное**.
4. Для **Фото** по умолчанию выбран экспорт **оригиналов** без перекодирования (экономит место и сохраняет HDR); при необходимости выберите оригиналы + JPEG, JPEG или TIFF. При необходимости включите MOV для Live Photos и задайте качество JPEG (по умолчанию 97). Для **Видео** настройки упрощены: файлы MOV/MP4 копируются без перекодирования и потери качества.
5. Выберите организацию файлов: **По годам и месяцам (`2026-10`)**, **Без разделения на папки** или **Оригинальная структура**. Нажмите экспорт.
6. Дождитесь окончания и проверьте результат в выбранной папке. В процессе видны имя файла, прогресс, скорость и приблизительное оставшееся время. При USB-экспорте без полного размера медиатеки оставшееся время оценивается по числу завершённых файлов. При поиске можно нажать **Остановить поиск**; если кабель отключён или AFC не отвечает, приложение прекращает поиск с ошибкой, а не продолжает бесконечно показывать анимацию.

При выборе месяца используется дата съёмки из доступных метаданных; если её определить нельзя, дата не выдумывается. Для Live Photo при экспорте группы «Фото» обычно сохраняются фото (HEIC/JPEG) и парный MOV, если включена соответствующая опция; сопоставление по имени и папке не гарантирует всех случаев. В группе «Видео» доступны все MOV/MP4, в том числе MOV от Live Photos. Если они уже были перенесены вместе с фотографиями, повторный USB-экспорт использует реестр проверенных файлов и пропускает неизменённые копии. Исходные видео не конвертируются.

### Поддержка видео и особенности медиатеки iPhone

- Поддерживаются **MOV и MP4**, в том числе обычные видеоролики и MOV-компоненты Live Photos. Видео сохраняются в исходном формате, без сжатия или перекодирования.
- Переключатель **«Фото / Видео»** разделяет списки для удобства выбора; при экспорте фотографии можно сохранить вместе с парными MOV.
- Hush Photo читает доступные файлы каталога **DCIM через AFC**. Список может включать файлы из альбома **«Недавно удалённые»**; приложение не определяет принадлежность к этому альбому и не удаляет такие файлы на iPhone.
- Счётчики файлов AFC и объектов в приложении «Фото» могут отличаться: Live Photo состоит из нескольких ресурсов, а отдельные файлы могут иметь иные имена в Проводнике Windows.
- Если конкретный ролик не удалось скопировать через AFC, он отмечается как ошибка в отчёте. Это не означает, что файл отсутствует в «Фото»; при необходимости проверьте копирование через Проводник Windows. Скопированные вручную файлы не регистрируются автоматически в манифесте приложения.
- Если видео с iPhone воспроизводится с артефактами только в стандартном плеере Windows, проверьте оригинал в VLC: причина может быть в поддержке HEVC/HDR проигрывателем, а не в экспорте.

### Интерфейс и выбор файлов

- Интерфейс автоматически подстраивается под светлую или тёмную тему Windows. Стартовый экран показывает подключение iPhone или выбор локальной папки; до появления файлов скрыты поиск, фильтры, сетка и навигация. Карточка устройства меняет оба текста при поиске, завершении сканирования и экспорте. После успешного экспорта список файлов остаётся доступным: закрытие AFC-сеанса не означает отключение iPhone и не требует нового сканирования. При явной ошибке USB-соединения устаревший список блокируется до повторного поиска. Ошибки поиска отображаются прямо в окне с возможностью повторить попытку.
- Большая медиатека отображается страницами по 36 элементов. Кнопки **Назад** и **Далее** позволяют просмотреть все найденные файлы, а не только первые 160.
- Выбор фотографий и видео сохраняется при переключении групп. Подфильтры **Все видео / Видеоролики / Live Photos** ограничивают **и счётчик на кнопке, и сам экспорт**: например, при 71 выбранном видеоролике кнопка покажет 71, даже если отдельно выбраны MOV-компоненты Live Photos. Возврат к другому подфильтру восстанавливает сделанный там выбор. Поиск фильтрует видимые файлы: **Выбрать всё** и **Снять выбор** действуют на текущую выборку поиска, не сбрасывая скрытые файлы.
- Для фотографий по умолчанию выбрана группировка по месяцу съёмки (`YYYY-MM`), для видео — исходная структура. При отсутствии достоверной даты используется папка **Без даты**.

## 4. Повторный экспорт и данные на диске

- При USB-экспорте приложение ведёт локальный реестр уже экспортированных файлов; при повторном экспорте проверенные копии пропускаются. Для локальных папок повторный экспорт сравнивает SHA-256 и не создаёт копии идентичных файлов, но сохраняет разные файлы с одинаковыми именами. Если соединение прервалось, повторите экспорт: полностью скопированные файлы сохраняются, текущий неполный файл копируется заново.
- Проверка SHA-256 относится к локально полученному файлу и реестру; она **не является** независимым сравнением хеша с iPhone.
- В папке назначения создаётся временный каталог `.hushphoto-staging` (служебные файлы удаляются после операции, пустые папки могут остаться). Не удаляйте его во время импорта.
- Кэш миниатюр: `%LOCALAPPDATA%\HushPhoto\previews` — только уменьшенные JPEG до 320×320. Фотографии подгружаются по видимой области небольшими партиями, без полной загрузки медиатеки и без сброса позиции прокрутки. Для создания миниатюры оригинал может временно целиком читаться с iPhone; временная копия удаляется после обработки. **При обычном закрытии Hush Photo кэш миниатюр очищается.** После аварийного завершения остатки будут удалены при следующем запуске. Очистка никогда не затрагивает папку экспорта.
- Для архива без потери исходных данных выбирайте **оригиналы** и MOV; режим **оригиналы + JPEG** удобен, если нужны также копии для просмотра. JPEG перекодируется с потерями; полноценный HDR → SDR tone mapping не гарантируется, поэтому сохраняйте оригинальный HEIC.

### Сборка portable и диагностика

Для обычного запуска из исходников используйте `start_windows.bat`: скрипт устанавливает зависимости только при их отсутствии. Для создания EXE используйте **`build_portable.bat`**. Сборка выводит отдельные шаги `[1/5]…[5/5]`: среда Python, зависимости, тесты (включая проверку Tk-разметки на Windows), PyInstaller и ZIP. Не закрывайте PowerShell сразу после ошибки: текст последнего шага показывает причину. Для пересборки сначала закройте запущенный `HushPhoto.exe`.

## 5. Если iPhone не обнаружен или не загружаются фото

- Проверьте USB-кабель, разблокировку, доверие устройству и установку Apple Devices.
- В папке с `afcclient.exe` проверьте в PowerShell: `.\idevice_id.exe -l` и `.\afcclient.exe ls /DCIM`.
- Если запускаете portable EXE, проверьте наличие `native\afcclient.exe` и DLL рядом с приложением. Пересоберите EXE после изменения исходников; старый EXE автоматически не обновляется.
- Фотографии, оригиналы которых находятся только в iCloud, могут быть недоступны по USB — загрузите оригиналы на iPhone.
- При ошибках экспорта не удаляйте оригиналы на телефоне. Сначала проверьте созданные файлы.

**Примечание:** USB-реализация зависит от версии iOS и установленных библиотек; автоматические тесты не заменяют проверки на реальном iPhone.

### Очистка служебных каталогов

После экспорта приложение удаляет **только пустые** каталоги `.hushphoto-staging` и `DCIM` (в режиме распределения по месяцам после переноса). Непустые папки и незавершённые файлы не удаляются. Если выбран режим сохранения исходной структуры, `DCIM` остаётся, поскольку содержит фотографии. Файлы `.hushphoto-manifest.json` и `hushphoto_last_export.json` нужны для контроля повторного экспорта.
